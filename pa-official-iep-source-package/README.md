# Official Pennsylvania IEP Source Package

This package collects the official Pennsylvania/PDE/PaTTAN source locations for IEP-related forms identified during research.

## Important note

The PaTTAN school-age IEP files are exposed through a web-page dropdown rather than as stable direct file URLs in the searchable page text. In this environment, the direct PDF/DOCX binary downloads could not be retrieved automatically. This package therefore contains the official source registry, links, and download instructions rather than embedded copies of the PDF/DOCX form files.

## Primary official sources

1. **PaTTAN — Individualized Education Program (IEP)**
   - Type: Official school-age IEP form
   - Effective date shown on source page: July 1, 2025
   - Available on source page: PDF and DOCX
   - URL: https://www.pattan.net/Forms/Individualized-Education-Program-IEP-1-1

2. **PaTTAN — Individualized Education Program (IEP) (Annotated)**
   - Type: Official annotated school-age IEP guidance form
   - Effective date shown on source page: January 1, 2026
   - Available on source page: PDF and DOCX
   - URL: https://www.pattan.net/Forms/Individualized-Education-Program-IEP-1-1-1

3. **Pennsylvania Department of Education — Early Intervention Forms**
   - Type: Official PDE Early Intervention forms hub
   - Includes links to Early Intervention IEP and annotated IEP forms
   - URL: https://www.pa.gov/agencies/education/programs-and-services/instruction/early-learning/early-intervention/forms

## Recommended manual download steps

1. Open the PaTTAN school-age IEP page.
2. Under "Download this Form," select either the PDF or DOCX file.
3. Save both versions if needed.
4. Repeat for the annotated IEP page.
5. For Early Intervention, open the PDE Early Intervention Forms page and follow the linked PaTTAN items:
   - Individualized Education Program with Annotations (IEP)
   - Individualized Education Program

## Recommended app use

- Use the non-annotated school-age IEP as the canonical Pennsylvania school-age schema reference.
- Use the annotated school-age IEP as the guidance source for field help, validation, review prompts, and AI-assisted explanation.
- Use Early Intervention IEP forms as future scope unless the MVP specifically includes preschool / EI workflows.
